Требуется разработать пользовательский интерфейс для отправки и получения сообщений в Telegram

Требования:

1. Требуется разработать пользовательский интерфейс для отправки и получения сообщений в Telegram
2. Требуется использовать сервис GREEN-API https://green-api.com/telegram
3. Требуется реализовать отправку и получение только текстовых сообщений
4. Требуется за прототип интерфейса взять внешний вид чата Telegram
5. Требуется реализовать интерфейс максимально простым с минимальным набором функций
6. Требуется отправку сообщений реализовать методом https://green-api.com/v3/docs/api/sending/SendMessage/
7. Требуется получение сообщений реализовать методом https://green-api.com/v3/docs/api/receiving/technology-http-api/
8. Требуется использовать технологию React

Ожидаемый результат:

- Пользователь переходит на сайт чата и вводит свои учетные данные из системы GREEN-API (idInstance, apiTokenInstance)
- Пользователь вводит номер телефона получателя и создает новый чат
- Пользователь пишет текстовое сообщение и отправляет его получателю в Telegram
- Получатель отвечает на сообщение в мессенджере Telegram
- Пользователь видит ответ получателя в чате
